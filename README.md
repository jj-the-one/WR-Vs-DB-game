# WR vs DB

Welcome to the **WR vs DB** project repository!

This repository contains the project files and resources for the WR vs DB game, developed using Unity.

## Project Files
This is the main location for all project files, scripts, assets, and other resources associated with the game.

## Unity Integration
GitHub is used directly with Unity to manage and access the project files. Changes made to the repository can be synchronized with the Unity project, allowing the repository to serve as the central location for project development and version control.

## Important
- All game-related project files are stored in this repository.
- Unity is used directly with this GitHub repository.
- Keep the repository updated with the latest project changes.
